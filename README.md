# Bank Loan Analysis Dashboard

## 📌 Project Overview

This project analyzes bank loan data using Microsoft Power BI to understand loan applications, loan performance, customer information, payment activity, and loan status.

The dashboard provides interactive visualizations and KPIs that help identify important patterns and trends in the loan portfolio.

## 🎯 Project Objectives

- Analyze total loan applications
- Analyze loan amounts by year
- Compare verified and non-verified loan payments
- Analyze loan status by state and month
- Analyze revolving balance by grade and sub-grade
- Analyze home ownership and last payment information
- Identify important trends and patterns in loan data

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Visualization
- Data Cleaning
- Data Analysis

## 📊 Dataset

The project uses two Excel datasets:

- Finance_1.xlsx
- Finance_2.xlsx

The datasets contain information related to customer loan applications, loan amounts, loan status, grades, sub-grades, payment information, employment details, home ownership, and geographical information.

## 🧹 Data Preparation

The data was cleaned and transformed using Power Query.

The following data preparation activities were performed:

- Removed duplicate records
- Handled missing and null values
- Corrected data types
- Renamed columns
- Combined data from multiple Excel tables
- Created calculated columns
- Prepared the data for analysis
